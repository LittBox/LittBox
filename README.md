## 01 / Research notes · 从信号到知识

<img src="./.github/profile/research.svg" width="100%" alt="研究方向概念图：示意 EEG 波形，以及从文献阅读、实体与关系提取、证据校验到知识图谱的多智能体工作流。波形为合成示意，不代表真实实验数据。" />

**脑机接口 / EEG**<br>
当前关注脑电信号与数据研究，想进一步理解如何从复杂、带噪的信号中提取有意义的信息。

**多智能体 / 知识图谱**<br>
探索多个智能体如何协作完成知识整理与图谱构建。关心的不只是“生成了什么”，也包括知识从哪里来、关系是否可靠、过程能否追溯。

**软件工程 / 研究实现**<br>
把学习、原型和工具持续放进仓库，让研究想法有可以阅读、运行和迭代的实现。
